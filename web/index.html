01 Add your DDR reference files

Choose the Hatsune Miku custom-mod folder used as the export template. Add stock Emi and animation files for comparison.

Template required: pl_miku00.model, .b2it, .grp2it and its DDS textures.

Where are these files?

Use your own files from DDR’s custom models and background dancers. You can add folders separately. Supported animation archives: mc_female.arc and mc_bpm120.arc. Stock reference: pl_emi00.arc and pl_emi00_face01.arc. Game and model assets are not included.

02 Bring your model

Blender is not connected.

This .blend file needs Blender to extract its meshes. Install Blender, then double-click Start Exporter.cmd again. The launcher will detect Blender and open the conversion page. If Blender is already installed, reopen the launcher to connect.

Advanced: bone mapping

Common MMD bone names are mapped automatically. For other rigs, choose a JSON map from source names to DDR bone names. Blender uses its own rig mapping.
