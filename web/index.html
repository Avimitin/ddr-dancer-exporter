DDR Dancer Exporter
PMX · browser conversion

Convert a model to a DDR dancer

You need your source model, a compatible DDR dancer reference, and creator credits. Animation files are optional. Files are processed on your computer.

1. Your source model Required

Choose the model you want to convert. Include its texture images and keep their original folder structure.

If you have a PMX model

Select the .pmx file and all referenced texture images (.png, .jpg, .tga, etc.). The easiest option is the whole model folder or a ZIP of it. Blender is not required.

If you have a Blender model

Select the .blend file alone if its textures are packed inside it. Otherwise choose the whole model folder or a ZIP that includes the external textures. The scene needs a mesh with an armature and skin weights, and the Blender backend must be connected.

Extract RAR files first. Don’t rename texture folders. A standalone PMX file usually does not contain its textures.

Blender is not connected.

To import this .blend file, install Blender, then run Start Exporter.cmd again to start its local backend. This page will enable Blender conversion when the backend connects. If Blender is installed already, rerun the launcher.

Optional: custom bone mapping

Common MMD bone names are mapped automatically. For other PMX rigs, supply bone-map.json, mapping source bone names to DDR bone names. Blender uses its own rig mapping.

2. DDR conversion reference Required

Choose an existing DDR dancer’s model folder. This supplies the DDR skeleton and file layout used to build your new dancer.

Which folder should I choose?

Use the model subfolder from a compatible DDR custom-dancer package, usually under data_mods/custom_models/dancers/<dancer>/pl_<id>/.

  • pl_<id>.model — the existing DDR model
  • pl_<id>.b2it and pl_<id>.grp2it — matching lookup files
  • Every .dds texture referenced by that model

Choose all of these from the same dancer. A PMX, .blend, registration text file, or texture folder alone is not a DDR reference. Game and model files are not included.

Only the exporter’s supported DDR layout can be used. The checks below show whether your selection is complete and compatible; not every DDR dancer is supported.

Choose a DDR model folder to check its files.

  • Needed: DDR .model
  • Needed: matching .b2it and .grp2it
  • Needed: referenced .dds textures

Preview files Optional

You can convert and download without these. With no animation loaded, the preview shows the rest pose.

DDR dancer animations

Choose dancer-motion archives (mc_*.arc) from your game’s original data/ directory, or extracted .anm motion files. You can add multiple animations.

For modded installations, also look under data_mods/background_dancers/ and its subfolders. Choose dancer motions; camera tracks (.camanm) and MP4 videos cannot animate the model.

No animations loaded — rest pose only.

Stock dancer for comparison

Choose any dancer from your game’s original data/ directory. Look in its subfolders for dancer archives (pl_*.arc), or select an extracted .model with all its .dds textures. There is no required character.

If the dancer has a separate face, include its matching face archive or model and textures too. You can also compare with a custom dancer from data_mods/custom_models/dancers/. The page lists the models you load and checks preview compatibility automatically.
